ASCII → Height Grid → Pseudo-3D Raycast

This extension turns a typed ASCII string into an m×n 2D height array, then
draws a first-person raycast of that map on the Animator canvas. Each character
becomes a cell height: '.' and spaces are empty, '#' / '@' / '*' are tall walls,
digits 1–9 set explicit heights, and other marks are medium walls. Rows are
padded so the grid is rectangular; the UI shows the live m×n dimensions.

With ASCII raycast mode on, the shape slider orbits the camera. Each screen
column casts a ray through the grid; hits become ColorLine vertical strips whose
length and shade depend on distance and wall height, so closer walls look taller
and brighter. A small top-down inset of occupied cells is drawn in the corner so
you can see the 2D array while the 3D view updates. The map is stored in
localStorage and edited in a dedicated textarea under the code panel.

The earlier Colored Geometry Toolkit remains: ColorLine, Circle, and ColorCircle
still work in normal draw mode. ASCII raycast is a separate mode so Gradescope's
Line/Path drawing tests keep using the interpreter unchanged.
